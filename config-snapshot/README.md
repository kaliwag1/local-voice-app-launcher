# Config snapshot

Copies of the files that live outside the project folders, so they are versioned too.
Restore by copying back:

- `qwaudio/*`  -> `C:\Users\JakeW\.config\qwaudio\`
- `opencode/*` -> `C:\Users\JakeW\.config\opencode\`

Re-run `Update Config Snapshot.cmd` after changing settings to refresh these copies.
